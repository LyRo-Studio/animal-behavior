# Project Instructions

Before discovery, planning, or implementation:

1. Read `ENGINEERING-STANDARDS.md`.
2. Read `CONTEXT.md`.
3. Treat `ENGINEERING-STANDARDS.md` as mandatory organisation-wide conventions.
4. Record project-specific terminology, decisions, constraints, and approved deviations in `CONTEXT.md`.
5. Do not silently deviate from the engineering standards.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues on `LyRo-Studio/animal-behavior`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
